# Dark Snow vehicle audio

`engine-loop.mp3` is an edited runtime copy of “Car Engine Loop” by qubodup,
recorded from an Opel Astra 1.6 16V with a Zoom H2.

- Source: https://freesound.org/people/qubodup/sounds/147242/
- Runtime input: https://cdn.freesound.org/previews/147/147242_71257-hq.mp3
- License: Creative Commons Attribution 4.0
- Credit: qubodup
- Published source: 96 kHz, 24-bit stereo WAV, 4 seconds
- Runtime file: Freesound's official 48 kHz stereo HQ preview

Dark Snow loops, filters, and pitch-modulates the recording at runtime according
to vehicle speed, throttle, load, and gear position.
